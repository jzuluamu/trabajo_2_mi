# Registro de decisiones de arquitectura (ADR)

Formato: Contexto → Decisión → Alternativas → Consecuencias. Un ADR no se edita para cambiar la
decisión; se crea uno nuevo que lo **reemplaza** y se marca el anterior como `Reemplazado por NNNN`.

Plantilla: copie `0000-plantilla.md` → `NNNN-titulo-corto.md` y agréguelo al índice de `docs/README.md`.
